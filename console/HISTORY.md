# WebAI 开发历史

## 2026-11-27

- 修复 `AskQuestion` 选择题反复追问与重复插入：提交选择或跳过后立即核销服务端 `pendingChoice` 并记录题目签名，同一题不再重弹；选择卡片增加「提交选择 / 跳过」按钮与双击提交，前后端同时拦截完全相同的排队/插入内容。
- 「已插入」的忙碌期消息在对应插入轮次执行完成或会话恢复空闲后自动清除，不再一直留在输入框上方。
- 工具栏「代理」旁新增「API Key」配置：密码框输入，先通过 `agent models` 在线校验有效性再替换保存（`0600` 权限），全程不回显明文并支持恢复默认登录态。

## 2026-11-25

- 输入框上方工具栏右侧增加对话区字体缩放（`A-` / `100%` / `A+`，80%–200%，本地持久保存）。
- 修复从 Ask / Plan 切回 Agent 模式不生效：Cursor CLI 会把模式写死在 `~/.cursor/chats/.../store.db`，切换模式和发起新一轮时同步更新 SQLite `meta` 记录。
- 修复流式事件偶发 `Unterminated JSON` 报错：服务端与网页端均改为按完整 JSON 值解析流，不再因单行分片或未转义换行中断整轮。

## 2026-11-20

- 本轮失败时直接写出具体原因（如 CLI 错误详情、stderr 或退出码），不再只显示「本轮失败」；刷新页面后原因也保留。
- 提问执行失败后，刚才的问题仍留在对话历史里并自动填回输入框，不必重新输入。
- 输入框上方模型旁增加「模式」选择（默认 / Agent / Plan / Ask），按会话记忆并传给 Cursor CLI。
- 输入框上方增加「代理」配置：支持在网页直接设置或清空 HTTP/HTTPS 代理（自动为所有会话、拉模型列表和新建会话注入 `HTTP_PROXY` / `HTTPS_PROXY`，本机 `127.0.0.1` 自动绕过）。
- 对话滚动到最顶部时显示「加载更多历史记录」，每次往前多加载 30 轮，保持当前阅读位置不跳动，直到第一条记录。
- 阅读历史向上滚动后不再被流式输出或轮询强行拉回底部；只有贴近底部或自己发新消息时才自动跟随。
- 修复执行新命令后上一条命令输出丢失：清理含换行的 `call_id` 避免选择器报错中断流，并在快照合并时保留已完成步骤的实时输出。
- 修复会话忙时「排队等待」和「插入」不执行：忙碌期间将本地队列通过 `/api/steer` 交给服务端，在当前 CLI 进程退出后同一流内接着运行。
- 会话列表交互整理：目录行右侧加 `+` 直接在该目录新建会话；改名与移除精简为 `R` / `-` 图标按钮；正在忙碌的会话与目录组统一用蓝色高亮；附着说明收进 `?` 悬浮提示。
- Markdown 渲染兼容紧贴正文的标题与表格（如句号/冒号后未换行直接跟 `##` 或表格头），避免排版粘连。

## 2026-11-19

- 网页左侧可直接选文件夹并 `create-chat` 开启新会话，不必先跑命令行包装。
- 附着会话按工作目录折叠；可「移除」离开网页列表，Cursor 对话仍保留，同目录再开还能选旧会话。
- 同目录已有旧会话时，「开启 Agent」先提示使用旧的还是新建，避免误开第二条。
- 修复「浏览」文件夹对话框不出现：选择窗口改为独立进程置顶弹出，不再把结果从被重定向的控制台里读出来。
- 会话可以改名。没有名字时，列表用这条会话的第一句问题当标题。
- 流式 JSON 被折行时不再把整轮标成失败；断行会接回去，接不上的那一行跳过。
- 监控里「修改」步骤对 Write/Delete 也显示前后对比；「命令」步骤展示完整输入、退出码、stdout/stderr。
- 监控步骤详情统一成「发起 / 经过 / 结果」三段，各类工具都能顺着看完发生了什么。
- 输入框上方可以选择模型。选择会记在这条会话上，下一条消息用 `--model` 发给 Cursor CLI。

## 2026-11-16

- 页头可以在「图形化」和「纯文本」两种阅读方式之间切换。
- Cursor 回复支持 Markdown，包括表格，以及 Mermaid 流程图、时序图等图形。Windows 和 Linux 共用这套页面。
- Linux 包装命令改为 `cursor-web`，避免和 Cursor 自带的 `agent` 冲突。Windows 仍使用 `bin/agent.cmd`，命令名和只监听 `127.0.0.1` 的行为不变。
- Linux 控制台监听 `0.0.0.0:3080`。第一次打开网页设置密码，之后打开窗口要校验；Windows 不启用这套密码。
- 工具步骤点开可看更多滚屏：子代理走 `/api/session/:id/scroll`，本地缓存完整文本，避免 2 秒轮询把内容抖回短提示。

- 步骤详情只保留一条滚动条；监控面板里由 `#raw` 滚动，线程里由 `.scroll-log` 滚动。
- 顶部当前问题最多 3 行，超出在问题区内滚动；滚动条与下方聊天历史右缘对齐。
- 从控制台会话列表剔除误附着的 Cursor IDE 本机对话（`db3a475d`），避免和网页/CLI 会话混在一起。

## 2026-11-13

- 修复页面脚本多出一个 `}` 导致整页 JS 不执行，左侧会话列表和历史空白。
- 会话忙时继续发送会进入队列，不再把「正在处理」画成失败；远端仍忙时也会排队，空闲后自动发出。
- 对话区顶部固定当前问题；记录里保留用户气泡并用青色区分。
- 每轮展示顺序改为：问题 → 工具步骤 → 结论；结束后显示「本轮已结束」。
- 支持终止当前轮（Esc / 终止按钮）、输入历史上下键、CLI 选择题面板。

## 2026-11-12

- 控制台从 Agent SDK 代理改为本机 Cursor CLI 共用会话：网页消息走 `stream-json`，终端进度读 agent-transcripts。
- 支持多会话并行；同一会话同时只处理一条网页消息。
- `agent --continue` 按目录附着：本地记录 → 控制台会话 → 有 transcript 的 Cursor 会话。
- 历史只加载最近几轮，降低大 transcript 卡顿；流式增量合并，避免一字一气泡。
- 监控时间线：步骤耗时、可视化改动、类型过滤（修改 / 命令 / 读取等）。
- 发送快捷键 Alt+S，按钮上显示提示。
- 增加 Linux 支持：`bin/agent`、`bin/ensure-console.sh`、`start-console.sh`；Windows 路径保持不变。
- 忽略运行态文件：`cli-sessions.json`、`last-by-cwd.json`、`bin/last-launch.txt`。
